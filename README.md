# Day-4-manual
Requirements

Explain about requirements with example?
    Requirements are the conditions or capabilities that a system must meet. They describe what the system should do and how it should                                 behave so that it satisfies user needs.

Types of Requirements:
----------------------
      *Functional Requirements
      *Non-Functional Requirements
      *Domain Requirements.
      
Functional Requirements: (What actions the system performs)
-----------------------
       These define what the system does (features or functions).
Examples:
    User authentication   : User should be able to log in using username and password
    Serach Functionality  : System should allow users to search products
    Report Generation     : System should generate reports for a selected date
 
Non-Functional Requirements:  (How well the system works)
---------------------------
      These define how the system performs (quality, performance, constraints).
Examples:
   Performance : System should handle 1000 users at a time. 
   Speed       : Page should load within 2 seconds. 
   Security    : Data should be encrypted.
   Reliability : System should be available 99.9% of the time.

Domain Requirements: (Rules specific to the industry)
---------------------
   These are specific to a particular industry or domain.
Examples:
   Banking system must follow RBI rules
   Healthcare app must follow patient data privacy laws
   E-commerce app should support payment gateways like UPI, cards 

Example (Login Feature):
------------------------
Functional Requirement:
      * User must be able to log in using valid credentials
Non-Functional Requirement:
      * Login should happen within 2 seconds
      * Password must be encrypted
Domain Requirement:
      * If it's a banking app, login must support OTP verification
